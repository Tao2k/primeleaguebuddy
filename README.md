# PrimeLeague Buddy

Zeigt automatisch die meistgespielten Champions des nächsten Prime-League-Gegners an.

## Idee

- Gegnerteam aus dem Prime-League-Spielplan ermitteln
- Spieler und ihre Accounts (Riot IDs) einsammeln
- Champion-Statistiken pro Spieler abrufen und die meistgespielten Champions übersichtlich darstellen
